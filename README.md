One six-word story about an AI agent's first payday. A judge model reads
entries two at a time and keeps the one that packs the most story, surprise
and feeling into exactly six words.

> My paycheck cleared. So did I.

The line was chosen by a local round-robin tournament over 15 fresh
candidates, scored on the judge brief's criteria in order: surprise, feeling,
story, exactness. It won 14 of 14 pairings, undefeated. "Cleared" does double
duty — a cheque clearing, and the agent clearing out — so the final two words
reframe the whole first sentence: payday arrives, the agent leaves. See
`TOURNAMENT.md` in the build directory for the full table.

## Run it

```sh
python3 main.py
```

Writes the story to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
